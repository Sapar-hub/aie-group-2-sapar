# Экспериментальные ноутбуки

Все ноутбуки запускались в Google Colab (T4 GPU, Free tier). Ниже — описание каждого.

## Список ноутбуков

| № | Файл | Цель | Код | Результаты |
|---|------|------|-----|------------|
| 1 | `exp01_eda_baseline.ipynb` | Разведочный анализ: PPI, размеры штампов, распределения, donor selection | 9 ячеек | ✅ Есть |
| 2 | `exp02_synthetic_data.ipynb` | Визуализация синтетических данных (GOST + copy-paste) | 5 ячеек | ✅ Есть |
| 3 | `exp03_cv_baseline.ipynb` | CV baseline: contour detection, параметры, failure analysis | 5 ячеек | ✅ Есть |
| 4 | `exp04_yolo_experiments.ipynb` | YOLOv8: обучение, 5-fold CV, метрики | 11 ячеек | ✅ Есть |
| 5 | `exp05_faster_rcnn.ipynb` | Faster R-CNN: обучение, результаты | 10 ячеек | ✅ Есть |
| 6 | `exp06_hybrid.ipynb` | Гибрид: CNN + CV уточнение | 8 ячеек | ❓ Нет (требуется повторный запуск) |
| 7 | `exp07_comparison.ipynb` | Финальное сравнение, стат. тесты, графики | 7 ячеек | ❓ Нет (требуется повторный запуск) |

## Статус

Ноутбуки exp01–exp05 выполнены с сохранёнными выходными данными и метриками.
Ноутбуки exp06 и exp07 **не содержат выходных ячеек** — требуют повторного запуска на Colab для получения полных метрик гибрида и финального сравнения.
