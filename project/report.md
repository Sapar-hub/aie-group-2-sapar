- **Название:** Детекция штампов ГОСТ на строительных чертежах (гибридный подход YOLO + CV)
- **Автор:** Сапармурадов Сапармурат

Проект реализует детекцию штампов ГОСТ на строительных чертежах с использованием 4 подходов: CV-базовая линия, YOLOv8n, Faster R-CNN и гибрид (YOLO + CV-уточнение). После сравнения моделей лучшая разворачивается как FastAPI сервис с `/predict` endpoint.

---

## 2. Постановка задачи и контекст

**Предметная область:** Автоматизация анализа строительной документации. Штампы ГОСТ содержат ключевую информацию (номер проекта, дата, масштаб). При оцифровке чертежей их нужно автоматически локализовать для последующего OCR.

**Задача в терминах ML:** Детекция одного класса объектов (`stamp`) на изображениях чертежей формата A1-A4. Вход — RGB-изображение чертежа, выход — bounding box штампа.

**Целевые метрики:**
- **IoU** (Intersection over Union) — основная метрика точности локализации
- **Precision / Recall / F1** — качество детекции при пороге IoU ≥ 0.5
- **Detection rate** — доля изображений, на которых модель находит штамп
- Время инференса — практическое ограничение для сервиса

## 3. Данные

**Источники:**
- 49 реальных изображений строительных чертежей из открытых источников (https://2d-3d.ru) с ручной разметкой штампов в формате YOLO
- 500 синтетических изображений (250 GOST + 250 copy-paste), сгенерированных автоматически

**Структура:**
```
data/
├── images/
│   ├── test/        # 49 реальных (31 PNG + 18 JPG)
│   └── train/       # 500 synthetic (PNG)
├── labels/
│   ├── test/        # 49 YOLO-разметок (.txt)
│   └── train/       # 500 синтетических разметок
└── gost_stamp.yaml  # YOLO dataset config
```

**EDA (exp01_eda_baseline.ipynb):**
- Размеры штампов: ширина 345–5652 px, высота 102–1254 px
- Aspect ratio: ~3.55:1 (среднее), std 0.41
- PPI: от 200 до 400 DPI (определено через метаданные + ISO 216)
- Физическая площадь штампа: сконцентрирована вокруг 10175 мм² (185×55 мм ГОСТ)
- 49 изображений, 1 класс (stamp)

**Синтетические данные (exp02_synthetic_data.ipynb):**
- GOST-метод: рисует штамп по ГОСТ 185×55 мм с сеткой, текстовыми полями
- Copy-paste: вырезает реальные штампы и накладывает на случайные участки чертежей

**Целостность данных (data leakage prevention):**
Copy-paste штампы вырезаются **только из 4 изображений-доноров**, отобранных стратифицированно по PPI, Laplacian-var и относительной площади ROI. Остальные 45 изображений модель видит впервые при валидации. Donor-лист: `data/donors.txt`.

## 4. Модели и подходы

### 4.1. CV Baseline (contour-based)
Классический компьютерный подход без обучения:
1. Adaptive thresholding + CLAHE
2. Поиск контуров с иерархией (parent + children)
3. Union box из дочерних контуров
4. Фильтрация по aspect ratio (3.55 ± 25%)

**Результат:** detection rate ~49%, IoU mean ~0.33

### 4.2. YOLOv8n (одностадийный CNN)
- Модель: yolov8n (pretrained on COCO)
- Данные: 500 synthetic train / 49 real val (eval на 45 non-donor)
- Параметры: 50 epochs, imgsz=640, batch=16, device=cpu, seed=42 (воспроизводимо)
- Аугментации: стандартные из ultralytics (mosaic=0.0, flip, rotation)
- Время обучения: ~144 мин (CPU) / ~5 мин (T4 GPU)

**Результат:** IoU mean = 0.88, Precision = 1.0, Recall = 1.0, F1 = 1.0, Detection rate = 100%

### 4.3. Faster R-CNN (двухстадийный CNN)
- Модель: ResNet50 FPN backbone (pretrained на COCO, `weights="DEFAULT"`)
- Данные: те же 500 synthetic train / 49 real val (eval на 45 non-donor)
- Параметры: 30 epochs, batch=4 (effective 8 с gradient accumulation), Adam с дифференциальным LR (backbone 1e-4, head 1e-3), imgsz=800, gradient clipping max_norm=1.0
- Early stopping с patience=5
- **Исправления:** `src/models/rcnn_model.py` — починена распаковка DataLoader, добавлен метод evaluate(), предобученные веса вместо инициализации с нуля, Adam вместо SGD, resize в predict()

**Результат:** (ожидает завершения ноутбука exp05)

### 4.4. Hybrid (CNN + CV Refine)
- Лучшая CNN → CV-уточнение:
  - Aspect ratio проверка
  - Edge density оценка
  - Выбор лучшего кандидата по композитному скору

**Результат:** (ожидает завершения ноутбука exp06)

## 5. Экспериментальный протокол и результаты

### Протокол
- Single train/val split (500 synthetic train / 49 real val)
- Метрики считаются на **45 non-donor** реальных изображениях (4 донора исключены, их штампы присутствуют в синтетическом train через copy-paste)
- Порог IoU ≥ 0.5 для Precision/Recall/F1

### Результаты

| Модель (eval: 45 non-donors) | IoU mean | IoU std | Precision | Recall | F1 | Det. rate | Время |
|--------|----------|---------|-----------|--------|-----|-----------|-------|
| CV Baseline | 0.330 | — | 0.490 | 0.490 | 0.490 | 49.0% | — |
| YOLOv8n | **0.880** | 0.074 | **1.000** | **1.000** | **1.000** | **100%** | ~2.5ч (CPU) / ~5мин (GPU) |
| Faster R-CNN | — | — | — | — | — | — | (ожидает exp05) |
| Hybrid (YOLO+CV) | — | — | — | — | — | — | (ожидает exp06) |

> **Примечание:** Результаты YOLO получены на 45 non-donor изображениях (4 донора с copy-paste штампами в train исключены из eval). Метрики Faster R-CNN и Hybrid ожидают запуска ноутбуков exp05 и exp06 на Colab.

### Выбор финальной модели
**Не может быть окончательно обоснован до получения метрик всех подходов.**
Предварительно: YOLOv8n показывает IoU 0.88 и 100% detection rate на тестовой выборке. Ожидается, что Hybrid (YOLO+CV) даст дополнительное улучшение за счёт фильтрации ложных срабатываний по aspect ratio и edge density.

## 6. Архитектура решения и сервис

```
[Upload Image] → FastAPI (/predict) → CNN (YOLO) → CV Refine → [bbox + confidence]
```

## 8. Ограничения и дальнейшая работа

**Ограничения:**
- Мало данных (49 real + 500 synthetic) — модель может не обобщать на новые форматы чертежей
- Только CPU inference в продакшене (без GPU)
- Только один класс (stamp)
- Faster R-CNN медленный на CPU
- DETR не реализован (stretch goal)
- Отсутствует Dockerfile

**Что можно улучшить:**
- Больше реальных данных (разметка + краудсорсинг)
- DETR (трансформерный детектор) при наличии GPU
- Сегментация штампов (не только bbox, но и маска)
- OCR текста внутри штампа
- Контейнеризация (Dockerfile)
