# Данные проекта

## Источники

- **49 реальных изображений** строительных чертежей из открытых источников:
  - [2d-3d.ru](https://2d-3d.ru) — 31 PNG + 18 JPG
  - Ручная разметка штампов в формате YOLO (class `stamp`, класс 0)
- **500 синтетических изображений**, сгенерированных автоматически:
  - 250 GOST — штамп, нарисованный по ГОСТ 185×55 мм с сеткой и текстовыми полями
  - 250 Copy-Paste — вырезанные штампы из 4 изображений-доноров, наложенные на случайные участки чертежей

## Структура

```
data/
├── images/
│   ├── test/          # 49 реальных изображений (31 PNG + 18 JPG)
│   ├── train_v1/      # 500 синтетических (train_v1, утечка фона)
│   └── train_v2/      # 500 синтетических (без утечки, 20 незав. фонов)
├── labels/
│   ├── test/          # 49 YOLO-разметок (.txt)
│   ├── train_v1/      # 500 синтетических разметок (.txt)
│   └── train_v2/      # 500 синтетических разметок (леakage-free)
├── unlabeled/         # 20 немаркированных фонов (независимый источник)
├── gost_stamp.yaml    # YOLO dataset config → images/train_v2
├── donors.txt         # 4 файла-донора для copy-paste
├── classes.txt        # Список классов (stamp)
└── notes.json         # Метаданные экспорта Label Studio
```

## Предотвращение утечки данных (data leakage)

Copy-paste штампы вырезаются **только из 4 изображений-доноров**, отобранных стратифицированно по PPI, резкости (Laplacian var) и относительной площади ROI (2×2×2 bins, rarest-first, centroid proximity). Остальные 45 изображений модель видит впервые только при валидации.

Donor-лист сохраняется в `data/donors.txt` и `artifacts/metrics/donors.txt` для воспроизводимости.

> **При формировании обучающей выборки copy-paste аугментации в качестве фонов использовались изображения из тестовой выборки с закрашенной областью штампа. Модель не видела тестовые штампы, однако видела тестовые фоны — это означает что высокие метрики (IoU 0.854, detection rate 97.8%) частично объясняются знакомой текстурой фона, а не истинной генерализацией. Для честной оценки необходимы фоны из независимого источника, не присутствующего в тестовой выборке.**

### train_v2 — устранение утечки (2026-05)

- 250 GOST + 250 copy-paste
- Copy-paste фоны из `data/unlabeled/` (20 изображений, независимый источник)
- Старые тестовые изображения больше не используются как фоны
- `gost_stamp.yaml` указывает на `images/train_v2`
- train_v1 сохранён для исторического сравнения метрик

## Формат разметки

YOLO format: `<class_id> <x_center> <y_center> <width> <height>`
- Координаты нормализованы (0..1) относительно ширины/высоты изображения
- Единственный класс: `stamp` (id = 0)
