# Данные проекта

## Источники

- **49 реальных изображений** строительных чертежей из открытых источников:
  - [2d-3d.ru](https://2d-3d.ru) — 31 PNG + 18 JPG
  - Ручная разметка штампов в формате YOLO (класс `stamp`, id = 0)
- **500 синтетических изображений**, сгенерированных автоматически:
  - 5 вариаций состава (v1–v4) — см. историю ниже

## Предотвращение утечки данных

Copy-paste штампы вырезаются **только из 4 изображений-доноров**, отобранных стратифицированно по PPI, резкости (Laplacian var) и относительной площади ROI (2×2×2 bins, rarest-first, centroid proximity). Donor-лист сохраняется в `data/donors.txt`.

Подготовка данных прошла **4 итерации** (v1→v2→v3→v4), каждая из которых закрывала определённый тип утечки или улучшала реалистичность:

### v1 — утечка фона (май 2026)

- 500 синтетических (250 GOST + 250 copy-paste, 80/20 split)
- Copy-paste фоны из **тестовых изображений** — штамп (целевой класс) накладывался
  корректно, но фон теста был виден при обучении. Модель выучила: фон теста = нет
  штампа, штамп на фоне теста = детекция
- **Метрики (завышены):** IoU 0.880, Precision 1.0, Recall 1.0, F1 1.0
- `train_v1/` сохранён для истории

### v2 — фоны исправлены, val синтетический (май 2026)

- 500 синтетических (250 GOST + 250 copy-paste, 80/20 split)
- Copy-paste фоны из `data/unlabeled/` (20 независимых фонов)
- Валидация YOLO на синтетике (92 изображения) — разделяет доноров с train
- **Метрики (45 non-donor):** IoU 0.765, Precision 1.0, Recall 0.844, F1 0.916

### v3 — чистый baseline (май 2026)

- 500 синтетических (250 GOST + 250 copy-paste, **весь набор на train**)
- Copy-paste фоны из `data/unlabeled/`
- **Валидация** переключена на 10 реальных non-donor (`val_honest/`)
- **Тест:** 35 реальных (4 донора + 10 val исключены)
- **Метрики:** IoU 0.700, Precision 1.0, Recall 0.778, F1 0.875
- **Невоспроизводим** за пределами Colab — см. `data/LEAKAGE.md`

### v4 — сложная синтетическая смесь (текущая)

- 500 синтетических: **50 GOST** + 250 copy-paste + **200 GOST-on-real-background**
- **GOST** уменьшен 250→50 (меньше "white canvas shortcut")
- **GOST-on-real-bg:** штамп на реальном фоне чертежа (без synthetic doodles)
- **Доноры обновлены:** PPI-экстракция расширила покрытие 27→49 изображений
- **Val_honest** перевыбран с исключением новых доноров
- **Тест:** 35 реальных (4 новых донора + 10 новых val исключены)
- **Метрики (YOLO v4 top-1):** IoU 0.579, Precision 0.885, Recall 0.657, F1 0.754
- **Метрики (Hybrid v4):** IoU 0.527, Precision 0.875, Recall 0.600, F1 0.712
- **Метрики (RCNN v4):** IoU 0.396, Precision 1.000, Recall 0.457, F1 0.627, Det. rate 45.7%

## Формат разметки

YOLO format: `<class_id> <x_center> <y_center> <width> <height>`
- Координаты нормализованы (0..1) относительно ширины/высоты изображения
- Единственный класс: `stamp` (id = 0)
