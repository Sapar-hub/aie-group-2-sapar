# Данные проекта

## Источники

- **49 реальных изображений** строительных чертежей из открытых источников:
  - [2d-3d.ru](https://2d-3d.ru) — 31 PNG + 18 JPG
  - Ручная разметка штампов в формате YOLO (class `stamp`, класс 0)
- **500 синтетических изображений**, сгенерированных автоматически:
  - 250 GOST — штамп, нарисованный по ГОСТ 185×55 мм с сеткой и текстовыми полями
  - 250 Copy-Paste — вырезанные штампы из 4 изображений-доноров, наложенные на случайные участки чертежей

## Предотвращение утечки данных (data leakage)

Copy-paste штампы вырезаются **только из 4 изображений-доноров**, отобранных стратифицированно по PPI, резкости (Laplacian var) и относительной площади ROI (2×2×2 bins, rarest-first, centroid proximity). Donor-лист сохраняется в `data/donors.txt`.

Подготовка данных прошла 3 итерации (v1→v2→v3), каждая из которых закрывала определённый тип утечки.

### v1 — утечка фона (май 2026)

- 500 синтетических (250 GOST + 250 copy-paste, 80/20 split на train/val)
- Copy-paste фоны из **тестовых изображений** — модель видела фоны теста при обучении
- **Метрики (завышены):** IoU 0.880, Precision 1.0, Recall 1.0, F1 1.0
- `train_v1/` сохранён для истории

### v2 — фоны исправлены, val синтетический (май 2026)

- 500 синтетических (250 GOST + 250 copy-paste, 80/20 split)
- Copy-paste фоны из `data/unlabeled/` (20 независимых изображений) — утечка фона устранена
- Валидация YOLO на синтетике (92 изображения) — разделяет доноров с train, возможен перекос
- **Метрики (честные на тесте, 45 non-donor):** IoU 0.765, Precision 1.0, Recall 0.844, F1 0.916
- `gost_stamp.yaml` → `images/train_v2`

### v3 — чистый baseline (май 2026)

- 500 синтетических (250 GOST + 250 copy-paste, **весь набор на train, без 80/20**)
- Copy-paste фоны из `data/unlabeled/`
- **Валидация YOLO** переключена на 10 реальных non-donor изображений (`val_honest/`, стратифицированная выборка)
- **Тест:** 35 реальных non-donor, non-val (4 донора + 10 val исключены)
- **Метрики (эталонные):** IoU 0.700, Precision 1.0, Recall 0.778, F1 0.875
- `gost_stamp.yaml` → `images/train_v3`, `val_honest`

### v4 — harder synthetic mix (май 2026)

- 500 синтетических (50 GOST + 250 copy-paste + 200 GOST-on-real-background)
- **Доноры обновлены:** тюнинг PPI-экстракции расширил покрытие 27→49 изображений, стратификация выбрала новые
- **GOST** уменьшен 250→50 (меньше "white canvas shortcut" сэмплов)
- **GOST-on-real-bg:** штамп на реальном фоне чертежа (без synthetic doodles — реалистичная текстура)
- **Val_honest** перевыбран с исключением новых доноров
- **Тест:** 35 реальных non-donor, non-val (4 новых донора + 10 новых val исключены)
- **Метрики:** pending
- `gost_stamp.yaml` → `images/train_v4`, `val_honest`

## Формат разметки

YOLO format: `<class_id> <x_center> <y_center> <width> <height>`
- Координаты нормализованы (0..1) относительно ширины/высоты изображения
- Единственный класс: `stamp` (id = 0)
